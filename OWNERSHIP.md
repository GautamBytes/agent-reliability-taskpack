## What the evidence establishes

The evidence establishes the recorded regressions, reference and incomplete-fix outcomes, the stated source/runtime versions, and the actual fresh coding-agent attempts. It does not establish exhaustive correctness, broad model difficulty, training-data non-contamination, employer experience or external benchmark acceptance.

The coding agents use one configured model family at two reasoning/deadline profiles. Every attempt starts in a new container with the original public task. Private tests and reference patches are absent during solving. A model/authentication proxy blocks direct internet access and GitHub retrieval. Historical issues may still be known through model training.

The verifier privilege boundary keeps rewards and trusted assertions separate from ordinary candidate execution. Better Auth still uses unprivileged compiler/Vitest results, and AnyIO retains a documented in-process completion-marker limitation. This is a functional evaluation with isolation and integrity controls, not a proof against every deliberately malicious submission.
