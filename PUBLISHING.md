# Public evidence edition

This repository publishes the previously verified v2 task pack. Its task source, private verifiers, submitted agent patches and recorded outcomes are unchanged. The tests were hidden from the coding agents during those attempts. They are now public so a reviewer can inspect them.

The public edition adds a short reviewer guide, screenshots of the saved result viewer, a GitHub Actions audit and a simpler application answer. Screenshots show recorded results. They are not screenshots of newly running agents and do not replace the linked logs.

The original local task-pack ZIP remains unchanged. SHA256SUMS in this repository describes this public edition. The current private task fingerprints remain in evidence/release-task-fingerprints.json.

PUBLICATION_METADATA.json records the later author-display and description edits. Only task metadata fields changed. Runtime settings, public instructions, verifier source, submitted patches and recorded outcomes remain unchanged.

Automated review is from the same available model family. Subjective portfolio scores are omitted from the public edition because they are not independent measurements. The underlying review findings and formatter checks remain available. No claim of external benchmark acceptance, employer commissioning or training-data independence is made.
